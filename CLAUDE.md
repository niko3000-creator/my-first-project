# Правила работы с проектом

## Структура и код

- Все страницы делаем в **одном HTML-файле**, без разбиения на отдельные файлы
- **Без внешних библиотек** — никаких React, Vue, Tailwind через CDN, jQuery и т.д. Только чистый HTML, CSS и JS
- CSS и JS пишем внутри HTML (в тегах `<style>` и `<script>`)

## Дизайн

- **Тёмный фон**, светлый текст
- **Акцентный цвет — оранжевый** (использовать для кнопок, ссылок, выделений)
- **Адаптивная вёрстка** — всё должно хорошо выглядеть на мобильных (mobile-first)
- Использовать `viewport` meta-тег и медиа-запросы

## Тексты

- Стиль: **простой, дружеский, без канцелярита**
- Обращение на «вы» с маленькой буквы
- Никаких «осуществить», «реализовать», «в рамках» — говорим как с человеком
- Короткие предложения

## Процесс работы

- **Перед созданием нового файла — сначала рассказать, что планируешь сделать**, и дождаться подтверждения
- Не плодить файлы без необходимости — править существующие
