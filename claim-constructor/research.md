# Исследование проекта: AI-конструктор претензий

## 1. КОНКУРЕНТЫ

### 1. Robotext.io — генератор претензий нейросетью
**URL:** https://robotext.io/write/complaint

**Что умеет:** Генерирует текст претензии/жалобы по описанию пользователя. Выбор типа обращения, указание адресата, описание ситуации — готовый текст за несколько секунд. Декларирует работу на базе российского законодательства.

**Плюсы:**
- Бесплатный базовый режим, без регистрации
- Простой интерфейс, минимум шагов
- Широкий спектр типов обращений

**Минусы:**
- Генерирует «болванку», а не юридически точный документ под ситуацию
- Нет проверки соответствия ст. 18–25 Закона о ЗПП
- Нет подсказок по правам потребителя и инструкции «что делать дальше»
- PRO-режим нужен для полного доступа, детали тарифов непрозрачны

### 2. ИИ-Юрист (ai-urist.ru) — Telegram-бот с юридическими консультациями
**URL:** https://ai-urist.ru/

**Что умеет:** Консультации по правовым вопросам, генерация договоров и заявлений, анализ документов. Работает через Telegram-бот, отвечает за 30–60 сек со ссылками на законодательство. Поддерживает голосовой ввод.

**Плюсы:**
- Тарифы от 390 ₽/мес — доступно для B2C
- Пробный доступ 24 часа без регистрации
- Привычная среда Telegram, не нужно устанавливать приложение

**Минусы:**
- Telegram — не оптимален для структурированных юридических форм
- Нет специализации на защите прав потребителей
- Консультация не заменяет документ: пользователь сам должен оформить итог
- Нет экспорта в PDF/DOCX с правильными реквизитами

### 3. Гарантзакона.ru — генератор досудебной претензии
**URL:** https://garantzakona.ru/generator-dosudebnoj-pretenzii/

**Что умеет:** Специализированный конструктор досудебных претензий. Форма: данные сторон, суть требований, правовое основание. Формирует документ для печати.

**Плюсы:**
- Прямая специализация — точно попадает в задачу
- Бесплатный инструмент
- Основан на нормах ГК РФ и Закона о ЗПП

**Минусы:**
- Старый дизайн, нет AI-логики — просто шаблон с подстановкой
- Нет адаптивных подсказок в зависимости от ситуации
- Не помогает выбрать правильное требование
- Нет инструкции по вручению претензии и трекинга сроков

### 4. DoNotPay — AI-платформа прав потребителей (США)
**URL:** https://donotpay.com/

**Что умеет:** 200+ типов потребительских задач: оспаривание штрафов, отмена подписок, возвраты, жалобы, иски в мелкие суды. Генерирует письма и юридические документы через NLP.

**Плюсы:**
- Самый широкий охват потребительских сценариев
- Сильная автоматизация рутинных действий

**Минусы:**
- Только для США/Великобритании — в России неприменим
- В 2025 году FTC оштрафовала на $193 000 за недостоверные заявления: документы оказались неприменимы, реальной юридической проверки не было
- Репутация подорвана

- Продуманный wizard-интерфейс

## 3. UX И СЦЕНАРИИ

### Сценарий 1: «Срочный возврат» — хочет вернуть деньги прямо сейчас

**Путь:** Поиск «как написать претензию в магазин» → форма → 5–7 вопросов (что купил, когда, где, в чём дефект, что хочет) → готовый текст → скачать PDF → пойти в магазин.

**Время в хорошей реализации:** 4–7 минут.

**Что работает хорошо:** Прогресс-бар («шаг 2 из 5»), конкретные примеры в полях, автоподстановка юридических норм без участия пользователя.

**Что раздражает:** Огромная форма на одном экране с 20 полями; обязательная регистрация до просмотра результата; юридические термины без объяснений; результат только в виде текста без кнопки «скачать».

---

### Сценарий 2: «Исследователь» — не знает своих прав, приходит за пониманием

**Путь:** Вопрос «магазин отказал в возврате, что делать?» → читает FAQ → начинает wizard → по ходу получает подсказки «вы имеете право требовать возврат в течение 15 дней» → осознаёт права → заканчивает претензию.

**Что работает хорошо:** Контекстные подсказки, отображение прав по ходу заполнения, один вопрос за раз.

**Что раздражает:** Только шаблон без объяснений. Нет режима «помогите разобраться» для тех, кому нужно понимание, а не просто документ.

---

### Сценарий 3: «Повторный пользователь» — претензия отправлена, продавец молчит

**Путь:** Возвращается через 2 недели → открывает сохранённый документ → срок ответа истёк → получает подсказку «следующий шаг: жалоба в Роспотребнадзор или иск в суд» → генерирует следующий документ или находит юриста.

**Что работает хорошо:** Трекер сроков с уведомлениями, чёткая карта действий, сохранённые данные — не нужно вводить заново.

**Что раздражает:** Инструмент заканчивается на «документ создан» — пользователь не знает, что делать дальше. Нет связи между первым документом и следующим шагом.

---

### Общие UX-принципы лучших реализаций:
- **Mobile-first:** большинство приходят со смартфона прямо из магазина
- **Zero-friction старт:** первый шаг без регистрации
- **Прогрессивное раскрытие:** простые вопросы сначала, сложные детали — опционально
- **Эмпатичный тон:** «Понимаем, это неприятно. Давайте составим претензию вместе» — не «заполните форму»

## 4. ТЕХНОЛОГИИ

### Вариант A: Next.js + Claude API — полноценный веб-продукт ⭐ Рекомендуется

**Стек:** Next.js (App Router) + TypeScript + Tailwind CSS + Claude API (Anthropic) + Supabase + Vercel

**Плюсы:**
- Полный контроль над продуктом и данными
- Claude API показывает лучшее качество на русскоязычных юридических текстах
- Стриминг ответа — пользователь видит документ по мере генерации
- SEO-дружелюбность Next.js (критично: основной канал — органический поиск)
- Масштабируется легко

**Минусы:**
- Требует фуллстек-разработчика
- Время разработки MVP: 2–4 месяца
- Стоимость MVP: 150 000–700 000 ₽ в зависимости от исполнителя

**Стоимость API:** При 10 000 генераций в месяц (~2 000 токенов на запрос) — около $60/мес на Claude API.

---

### Вариант B: Простой HTML/JS + OpenAI API — быстрый MVP

**Стек:** Vue.js или Vanilla JS + GPT-4o-mini + Node.js/Express + Firebase

**Плюсы:**
- MVP за 2–4 недели
- Стоимость разработки: 50 000–150 000 ₽
- GPT-4o-mini дешевле: $0.15/млн токенов

**Минусы:**
- Сложно масштабировать, технический долг накапливается быстро
- Нет SSR/SEO из коробки — плохо находится в поиске
- OpenAI слабее понимает нюансы российского законодательства

**Вывод:** Подходит для быстрой проверки гипотезы, но придётся переписывать.

---

### Вариант C: No-code Bubble.io + OpenAI

**Стек:** Bubble.io + API Connector + встроенная БД

**Плюсы:**
- MVP без программиста за 2–4 недели
- Стоимость: от 0 + подписка Bubble от $32/мес
- Легко итерировать дизайн

**Минусы:**
- Слабое SEO — Bubble генерирует сложный JS, плохо индексируется
- Сложно интегрировать российские платёжные системы (ЮKassa, Tinkoff Kassa)
- Производительность деградирует при 1 000+ одновременных пользователей
- Vendor lock-in: миграция с Bubble дорогая

**Вывод:** Только для проверки концепции. Для продукта с SEO-трафиком — плохой выбор.

## 5. МОНЕТИЗАЦИЯ

### Freemium — наиболее перспективная модель

**Логика:** Пользователь бесплатно проходит wizard и видит превью документа, но скачать PDF или получить расчёт неустойки — только платно. Конверсия в B2C SaaS: 3–10%. Юридическая проблема острая — человек уже мотивирован, ему нужен документ прямо сейчас.

**Рекомендуемая реализация:**
- Бесплатно: заполнение wizard, просмотр текста онлайн
- Разово (149–299 ₽): скачать PDF + расчёт неустойки + инструкция по отправке
- Подписка (290–490 ₽/мес): безлимитные документы + напоминания + следующие шаги

---

### Pay-per-document — разовая оплата за документ

199–499 ₽ за одну претензию. Высокая конверсия при правильном ценообразовании — пользователь уже внутри продукта и осознал ценность. Минус: низкий LTV, сложно строить предсказуемую выручку.

---

### Подписка — работает при экосистеме

290–690 ₽/мес для российского B2C. Проблема: претензию пишут раз в год. Решение — делать подписку «юридического ассистента»: не только претензии, но и жалобы в Роспотребнадзор, иски в суд, другие документы.

---

### Лидогенерация для юристов — высокомаржинальный канал

Инструмент бесплатный, на финальном экране — «Хотите, чтобы юрист представлял ваши интересы?». Юристы платят за лид 500–3 000 ₽. Не требует оплаты от пользователя — снижает барьер входа.

---

### Реклама — слабая модель

Подходит только при трафике 100 000+ уникальных посетителей в месяц. Плохо совместима с доверием пользователя к юридическому инструменту.

---

### Итоговая рекомендация

**Гибридная модель: Freemium + Pay-per-document + Лидогенерация**

| Этап | Что делать |
|------|-----------|
| Старт | Бесплатный доступ без регистрации → максимальный охват |
| Монетизация | Разовый платёж 199–349 ₽ за PDF в момент «боли» |
| Рост | Подписка 390 ₽/мес для активных пользователей |
| Дополнительно | Лидогенерация для юристов-партнёров |

B2C юридические продукты конвертируют лучше разовой оплатой в момент острой потребности, а не подпиской. Подписка работает как апгрейд для тех, кому нужна экосистема.
